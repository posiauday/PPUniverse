# Third-party notices for the component library

LowCodeStacks components are written by LowCodeStacks. Where a component reuses or adapts code from an openly licensed source, the source, its licence and its copyright notice are listed here, and the component's guide says so (docs/final-decisions.md, 2026-10-08, "Component library: learning from MIT-licensed samples").

Only sources with an explicit open licence are used. Their websites, documentation, branding and logos are not reused. Icons are our own glyphs.

## Components that reuse or adapt code

None yet. Components so far are written from scratch; the samples above were used only to learn which controls, versions and structures Power Apps Studio accepts.

When code is reused, add a section here:

```
### lcsName
Adapted from: <source and component>, <URL>
Licence: MIT. <copyright line>
```
