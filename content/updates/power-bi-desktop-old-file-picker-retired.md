title: "Old Power BI Desktop versions lose OneDrive and SharePoint saving"
slug: power-bi-desktop-old-file-picker-retired
kind: RETIREMENT
technology: POWER_BI
action: "Update Power BI Desktop"
source: https://learn.microsoft.com/power-bi/fundamentals/whats-new
effective: 2026-10-01
replacement: "A current Power BI Desktop release"
---
From October 2026, Power BI Desktop versions from March 2026 or earlier can no longer save and share files to OneDrive and SharePoint, because the old file picker is being retired. Update Power BI Desktop to keep saving there.
