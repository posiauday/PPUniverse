technology: POWER_APPS

effective: 2026-03-01
replacement: "Power Apps grid control"
---
Since March 2026, the Editable Grid and Power Apps Read-Only Grid controls in model-driven apps get critical security fixes only. They still work for now. Find the views and subgrids that use them and move them to the Power Apps grid control, which handles both read-only and inline editing.
