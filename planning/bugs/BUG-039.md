## Summary
The product owner's first paste-test of lcsNavShell 0.1.0 (a draft, not published) showed two problems:
- **An error on the badge's X:** "'TemplateMax' is an unknown or unsupported function in namespace 'galBottom'". The side menu's badge "3" sat on top of the Orders icon.
- **No icon for Reports.**

## Cause
- **The badge.** The generator put the badge's width into its X formula by replacing the letter "W". That also replaced the "W" in `TemplateWidth`, which produced `Parent.TemplateMax(...)idth`. Both badges (side menu and bottom bar) were affected. It was valid YAML and passed Microsoft's schema, so CI didn't notice.
- **The icon.** `ChartMultiple` isn't in Power Apps' icon set. The modern controls use about 180 icons, the same set as the classic icons, so a Fluent name outside that set shows nothing.

## Fix
- **The badge:** the generator uses a placeholder that can't occur in a formula. The badge is now right-aligned in the row, and beside the icon in the bottom bar.
- **The icon:** Reports uses `Document`.
- **The Tree view,** not yet paste-tested, now avoids names outside the classic set as well: `FolderOpen` and `Image` are gone, and files use `Document`.
- **A new CI check** (`component-files.test.ts`) fails any component whose formulas read a `Parent.` property other than Width, Height, TemplateWidth and TemplateHeight. Run against the old YAML, it names `TemplateMax` twice.

## Expected behavior
The badge sits at the right of its row, Reports shows an icon, and no formula has an error.
