## Summary
GitHub advisory GHSA-wq5f-xc86-pv6w (CVE-2026-96889) was published 2026-10-06 at 13:43 UTC, with severity high. It covers a vulnerability in the librsvg library that sharp bundles, and affects sharp below 0.35.5.

The lockfile had sharp 0.35.4, an optional dependency of `next` (paths `apps__web>next>sharp`, and through `next-auth`). CI's dependency audit (`pnpm audit --audit-level=high`) therefore failed on every branch, first seen on PR #78.

## Severity
- [x] P0, by type: a high advisory in a runtime dependency.
- **Exposure: very likely none.** The app imports neither `next/image` nor sharp. Share images are drawn by `next/og` (Satori and resvg), not sharp. No user-supplied SVG reaches sharp.
- That is our assessment from the code, not a certainty. The upgrade is required either way.

## Steps to reproduce
Run `pnpm audit --audit-level=high` on `develop` at 2026-10-06, before this fix. It reports 1 high: sharp <0.35.5.

## Expected behavior
No high or critical advisories in the installed dependencies.

## Fix
- **Lockfile only:** sharp 0.35.4 to 0.35.5, published 2026-09-27, plus its own `@img/*` platform packages. Next 16.3.7's range `^0.35.4` already allows it, so no `package.json` changed.
- **Checks:** `pnpm audit --audit-level=high` reports no known vulnerabilities; `pnpm install --frozen-lockfile` and the web build pass.
- **Also on PR #78:** the same lockfile commit is applied there, so that PR's checks can pass too.
