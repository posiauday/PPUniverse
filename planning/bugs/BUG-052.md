Follows `planning/github/04-bug-template.md`. Found in the admin centre review the product owner asked for on 2026-10-10.

## Summary
At 320 px, /admin/settings was 351 px wide: the page scrolled sideways (WCAG 2.2 reflow, 1.4.10).

## Cause
Below the lg width the admin layout is one grid column sized to its content, so a long unbreakable word (a setting name in code) widened the whole page.

## Fix
The column is minmax(0, 1fr) and long words wrap, so every admin page fits the screen. Checked with axe and a sideways-scroll check on eight admin pages at 320, 375, 768 and 1280 px, light and dark.
