## Summary
Reported by the product owner with a screenshot. The "On this page" list on guides only had a hover style, so its bar never moved while scrolling and readers could not see where they were.

## Severity
- [x] P3: makes long guides harder to follow. No data or security impact.

## Steps to reproduce
1. Open a long guide at 1024 px or wider, for example `/learn/dynamic-row-level-security`.
2. Scroll down: no entry in "On this page" is marked as current.

## Fix
- `TocSpy` (`apps/web/app/learn/TocSpy.tsx`) marks the link of the section being read with `aria-current="location"`; `ArticleToc` styles it with the primary-colour bar and bold text.
- Nothing is marked above the first heading; at the very bottom the last section is.
- Without JavaScript the list stays a plain set of links.
- **Checked** on the live guide's DOM with the same logic: at 0, 900, 1,800, 2,700 px and the bottom, the marked section was none, none, the second, the third and "Sources".

## Accessibility impact
- [x] Improves it: screen readers announce the current section link ("current location").
