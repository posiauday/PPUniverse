Follows `planning/github/04-bug-template.md`. Found while measuring the accessibility baseline for MVP-023.

## Summary
The global focus rule is `:focus-visible { outline: 2px solid currentColor; outline-offset: 2px }`. On a control whose text is near-white (the primary "Search" button, `text-primary-foreground` on `bg-primary`) the ring is drawn near-white outside the button, over a white page, so keyboard focus cannot be seen.

## Severity
- [x] P2 — degraded search, notifications, or creator workflow (keyboard users cannot see where focus is on the primary search control)

## Affected requirement / feature
- NFR-001 — visible focus. WCAG 2.2 success criteria 2.4.7 Focus Visible (AA) and 1.4.11 Non-text Contrast (focus indicator).
- Delivered by MVP-003/004 (`apps/web/app/globals.css`, `packages/ui/src/search-form.tsx`).

## Environment
Local dev server, Chromium, real local Postgres with throwaway rows, 2026-09-21. Guest.

## Steps to reproduce
1. Open `/categories/power-apps-components`.
2. Press Tab twice (search input, then the Search button).

## Expected behavior
A focus indicator with at least 3:1 contrast against the adjacent background.

## Actual behavior
The button receives focus (`:focus-visible` matches) but no ring is visible.

## Evidence
Computed on the focused button: outline `2px solid` near-white (`lab(97.68 …)`); contrast against the page background **1.06:1**; against the button's own background 7.18:1. Screenshot after the Tab presses shows no ring. axe cannot detect this.

## Security or privacy impact
- [ ] None.

## Accessibility impact
- [x] Blocks WCAG 2.2 AA conformance (2.4.7, 1.4.11). Apply `type:accessibility`.

## Suggested fix
Use a focus colour that does not depend on the element's text colour (for example the primary colour, or a two-tone ring that meets 3:1 on any background), with a test asserting indicator contrast for every focusable element.

## Resolution
Fixed by MVP-023 F1 (commit 488236f): the global `:focus-visible` ring uses the foreground token instead of `currentColor`. Re-measured on 2026-09-21 from computed style and, independently, from painted pixels in chromium, firefox and webkit: 18.13:1 (was 1.06:1). Regression test: `packages/e2e/tests/a11y/regressions/bug-003-focus-indicator.spec.ts`, shown failing before the fix.
