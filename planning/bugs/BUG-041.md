## Summary
Found by the product owner, signed in: the library list beside each component page marked sign-in-to-copy components \"sign-in\", as if they still had to sign in.

## Cause
`LibraryNav` showed the note for every `MEMBERS` component without knowing whether the reader was signed in.

## Fix
The component page passes `signedIn` (it already reads the session), and the note shows only to signed-out readers. Tests: `apps/web/app/components/LibraryNav.test.tsx`.

## Expected behavior
Signed in, no \"sign-in\" notes; signed out, the note on each component that needs an account to copy.
