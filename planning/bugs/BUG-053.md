Follows `planning/github/04-bug-template.md`. Found while restyling the Learn editors in the admin centre redesign (MVP-052 phase 4).

## Summary
On /admin/topics each draft topic's Publish button sits in a paragraph. After a successful publish the button is replaced by a "Published." message that was itself a paragraph, so the page had a paragraph inside a paragraph: invalid HTML, and React warns about it in development.

## Cause
`LearnPublishControl` returned `<p role="status">` for the published state, while its other state is a `<span>`, which suits the paragraph it is placed in.

## Fix
The published message is a `<span role="status">`, like the control's other state, so it fits wherever the control is placed. Screen readers still hear it, as before.
