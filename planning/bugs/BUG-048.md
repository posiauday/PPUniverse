Follows `planning/github/04-bug-template.md`. Found in the full-site code review the product owner asked for on 2026-10-10.

## Summary
The crown can only be chosen by an admin (2026-10-08), but changeRole didn't touch the avatar, so someone demoted to member kept it beside their comments.

## Cause
The rule was enforced when choosing an avatar, not when the role changed.

## Fix
Demoting an admin who wears the crown gives them a new critter avatar, in the same transaction as the role change.

## Steps to reproduce
An admin chooses the crown; another admin makes them a member.

## Expected behavior
Their comments no longer show the crown.

## Actual behavior
The crown stayed.

## Security or privacy impact
Readers could trust a former admin's comments as staff advice.
