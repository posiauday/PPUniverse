## Summary
The product owner sent a note from the box at the end of a guide ("Did this fix it?", then "Something here changed?"). The thanks appeared, but the box stayed open with the note still in it, so it looked as if nothing had happened, or as if it could be sent again.

## Cause
When the note was sent, the form only removed its Send button and disabled the text box. The box and its text stayed on screen. Focus was also left on a button that no longer existed.

## Fix
Once the note is sent, the form closes and the thanks ("Thanks. We'll re-check this guide.") takes its place. Focus moves to the thanks, so keyboard and screen reader users hear it and aren't left nowhere (WCAG 2.4.3). The note is cleared (`apps/web/app/learn/GuideFeedback.tsx`).

The gate's `learn-report-sent` state now checks that the box is gone and focus is on the thanks.

## Expected behavior
Sending a note closes the box and shows the thanks in its place.

## Accessibility impact
- [x] Fixed: focus no longer lands on a button that has gone away after sending (WCAG 2.4.3, focus order).
