## Summary
The product owner's first paste-test of lcsDataTable 0.1.0 (a draft, not published) failed with four errors: "PA2108: Unknown property 'Checked' for control type 'ModernCheckbox@1.0.0'", one for each selection checkbox. Studio also warned that `ModernCheckbox@1.0.0` and `ModernTabList@1.0.0` are older than the current 1.0.2.

## Cause
Studio reads a control's properties by the version written after `@` (Microsoft Learn, "Power Apps YAML schema versions": "The version is used to deserialize the properties of the source code"). Version 1.0.0 of the modern checkbox has no `Checked`; the current 1.0.2 does. Microsoft's control page documents only the current properties, so the README marked the YAML name as "our best reading" until a paste-test.

## Fix
- The Data table asks for `ModernCheckbox@1.0.2`. Every other property it sets (`Label`, `BasePaletteColor`, `AccessibleLabel`, `OnCheck`, `OnUncheck`) is in 1.0.2.
- A new gate check (`component-files.test.ts`) fails any component asking for `ModernCheckbox@1.0.0` or `@1.0.1`. Run against the old YAML, it fails.
- `ModernTabList@1.0.0` only warns, and the Tabs component pasted with it, so it is unchanged.

## Expected behavior
The Data table pastes with no errors, and its selection checkboxes tick.
