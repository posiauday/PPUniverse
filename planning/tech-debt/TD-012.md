## What was deferred and why
Next.js declares `@playwright/test` as an *optional* peer dependency (for its experimental test proxy, which this app does not use). Once the `@ppu/e2e` workspace package exists, pnpm resolves that peer from the workspace and links Playwright into the web app's production dependency tree, which decision Q41 forbids (dev-only, not shipped). A pnpm `overrides` entry with the value `-` was tried first and did not remove a peer link. The root `.pnpmfile.cjs` therefore deletes the peer declaration from Next's manifest at resolution time. It is a workaround for how pnpm resolves optional peers across a workspace, not a fix at the source.

## Risk if left unresolved
- If a future Next.js changes how it declares the peer (or the app ever enables `experimental.testProxy`), the hook silently does the wrong thing or hides a needed link.
- A resolution hook is easy to forget; `pnpm install --frozen-lockfile` fails if the lockfile and hook disagree (`pnpmfileChecksum` is recorded in `pnpm-lock.yaml`), which is a safe failure but a surprising one.

## Proposed resolution
On each Next.js upgrade, re-check with `pnpm why @playwright/test` that the only dependent is `@ppu/e2e`, and try removing the hook. Prefer a declarative pnpm setting if one becomes available for ignoring optional peers.
