## What was deferred and why
The Daylight fonts (MVP-031) and Google Sans (the Google button) were loaded with `next/font/google`, which downloads them from Google Fonts during every build.

On 2026-10-07 one download failed in CI on the release PR #87: Turbopack reported "Module not found … next/font/google queries have exactly one entry" for Geist Mono. The same code had built a minute earlier in the other CI run. Netlify builds make the same downloads, so the same hiccup could fail a production deploy.

## Risk if left unresolved
Random build and deploy failures that need a re-run; nothing wrong with the code.

## Resolution
- The five font files are now in the repository at `apps/web/assets/fonts/`, each with its `OFL-*.txt` licence: Bricolage Grotesque, Instrument Serif italic, Geist, Geist Mono and Google Sans Medium.
- They are the Latin WOFF2 subsets Google Fonts serves, about 170 KB in total, downloaded with the product owner's approval.
- `apps/web/app/fonts.ts` loads them with `next/font/local`. It keeps the same CSS variables, weights, `display: swap` and size-adjusted fallbacks, so the site looks the same. A production build was checked to load each font.
- Builds no longer contact Google Fonts.
