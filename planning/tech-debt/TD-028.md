## What was done and why
On 2026-10-06 the CI dependency audit (`pnpm audit --audit-level=high`) began failing on every branch, including the MVP-033 release PR. The cause is GHSA-68fv-2mgg-jv7q: `source-map-js` before 1.2.2 can be made to loop on crafted indexed source maps (denial of service).

It reaches us only through build and test tooling: postcss, vite (via vitest) and css-tree (via jsdom). Nothing in the running site parses untrusted source maps. 1.2.2 is a patch release that every dependent's `^1` range already allows, so `pnpm-workspace.yaml` now overrides `source-map-js` to `>=1.2.2`. The lockfile has no 1.2.1 left, and `pnpm audit --audit-level=high` reports no known vulnerabilities.

## Risk if left unresolved
None for the site itself. The override is pinned to a floor, not a ceiling: it only prevents a vulnerable version from coming back.

## Proposed resolution
Remove the override once a fresh lockfile resolves `source-map-js` 1.2.2 or later without it.

## Trigger to revisit
The next dependency refresh: delete the override, run `pnpm install`, and check `pnpm why source-map-js` shows no version below 1.2.2.
