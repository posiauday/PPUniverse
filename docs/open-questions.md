28. **DISPOSITION RECORDED (2026-09-21, direct product-owner instruction — `docs/final-decisions.md`, "Product-owner decisions for MVP-021").** TD-008 is **not** folded into MVP-021: it is a separate small corrective change that must land before MVP-012 lets creators or administrators write compatibility evidence through the product editor (`planning/tech-debt/TD-008.md`, still Open). Only Creator Declared and Marketplace Reviewed are assignable; Marketplace Reviewed is a per-claim evidence status. **"Not Verified" is not an assignable persisted status**: unreviewed information is Creator Declared, absent information shows the approved empty state (no Not Verified record is created), and any existing Not Verified enum/database value is legacy or reserved — not removed destructively and not converted without inspecting provenance. A nullable reviewed-at timestamp is approved for compatibility claims: null for Creator Declared, set only by the trusted server-side moderation workflow on transition to Marketplace Reviewed, never accepted from a client, cleared (returning the claim to Creator Declared) if the creator materially changes a reviewed claim, and never fabricated for existing records. A moderator identity or review reference may be proposed in TD-008 but is not added without reviewing the moderation schema and approved scope. **Still open (for TD-008 / MVP-013):** how, and with what wording, a reviewed date is shown publicly; what counts as a "material" change; administrator authority over compatibility evidence; whether a moderator may withdraw a review.
29. **CLOSED (2026-09-21, direct product-owner instruction — `docs/final-decisions.md`).** A category with zero PUBLISHED products is not indexed (`noindex, follow`) and is excluded from `sitemap.xml`; it stays publicly reachable and does not return 404 merely because it is empty. Only PUBLISHED products count (never DRAFT, suspended, rejected, archived or unpublished). Indexability is derived from current published inventory, not from a manually edited flag.
30. **CLOSED (2026-09-21, direct product-owner instruction — `docs/final-decisions.md`).** Approved parameter-specific canonical policy: the base category page is `index, follow` with a self-canonical; a valid `?page=N` (N ≥ 2) is `index, follow` with a self-canonical to that exact URL, and `?page=1` is normalized to the base URL; invalid, zero, negative, non-numeric or out-of-range `page` values never become an indexable duplicate; `?q=`, sort-only, filter and mixed-parameter variants are `noindex, follow` with the clean base canonical and are excluded from the sitemap. The sitemap lists base category pages only. This is an intentional corrective SEO change owned by MVP-021, not a reopening of MVP-004; MVP-004's search and filtering behavior is unchanged.
31. **CLOSED (2026-09-21, direct product-owner instruction — `docs/final-decisions.md`).** Product JSON-LD ships now, without Offer data, using only fields backed by real PUBLISHED product data.
