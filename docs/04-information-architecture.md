# Information Architecture and Sitemap

## Primary navigation
Explore, Components, Templates, Automations, Power BI, Architecture, Governance, AI, Learn, Creators, Pricing.

## Utility navigation
Search, saved items, downloads, purchases, creator dashboard, notifications, account, support, admin when authorized.

## URL model
- `/products/[slug]`
- `/categories/[slug]`
- `/collections/[slug]`
- `/creators/[handle]`
- `/learn/[slug]`
- `/tools/[slug]`
- `/pricing`
- `/account/*`
- `/creator/*`
- `/admin/*`

## Product taxonomy
Platform, asset type, use case, industry, audience level, data source, connector, license, pricing model, compatibility, accessibility status, deployment method, support status, language and update recency.

## Page inventory
Home; search results; category landing; collection; product detail; creator profile; article/tutorial; learning path; pricing; enterprise; sign-in; account; library/downloads; orders; saved items; creator application; creator dashboard; product editor; release editor; moderation queue; admin dashboards; help center; contact; terms; privacy; cookies; marketplace agreement; acceptable use; refund policy; licensing explainer; takedown process.

## Search requirements
Autocomplete is optional for MVP. Required: query, filters, sort, total, pagination, clear-all, zero-results guidance and analytics. Search ranking inputs may include text relevance, quality, freshness and verified engagement but must not secretly favor paid products. Sponsored placement must be labeled.
