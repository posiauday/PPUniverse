# Architecture Gate

Use before implementing a new domain, integration, upload, payment, search, identity or admin capability. Identify trust boundaries, authorization, data classification, migrations, idempotency, failure modes, scalability, observability, rollback and ADR need. Block unsafe designs.

## Output
Provide a concise decision, evidence reviewed, requirement IDs, findings, changes made or required, tests, risks and follow-up owner.
