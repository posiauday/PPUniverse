# Accessibility Review

Use on any user-facing slice. Check semantics, headings, names, keyboard, focus, forms, errors, contrast, reflow, zoom, motion, media, tables and dynamic announcements. Include manual checks, not automation alone.

## Output
Provide a concise decision, evidence reviewed, requirement IDs, findings, changes made or required, tests, risks and follow-up owner.
