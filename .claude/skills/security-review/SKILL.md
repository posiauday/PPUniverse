# Security Review

Use for auth, commerce, downloads, uploads, admin and webhooks. Inspect object-level authorization, validation, rate limits, XSS, CSRF, SSRF, secrets, signed URLs, replay/idempotency, audit, privacy and abuse cases. Produce actionable findings with severity and tests.

## Output
Provide a concise decision, evidence reviewed, requirement IDs, findings, changes made or required, tests, risks and follow-up owner.
