# Release Readiness

Use before launch or release. Verify acceptance trace, test results, migration and rollback, backup/restore, feature flags, observability, security, accessibility, legal content, support readiness and known risks. Return GO, CONDITIONAL GO or NO-GO.

## Output
Provide a concise decision, evidence reviewed, requirement IDs, findings, changes made or required, tests, risks and follow-up owner.
