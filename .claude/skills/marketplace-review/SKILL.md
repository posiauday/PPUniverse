# Marketplace Review

Use for first-party product releases (reworded 2026-09-24, `docs/final-decisions.md`, "First-party-only publishing model" — no third-party creator submissions exist). Check ownership, license, claims, metadata, compatibility, accessibility, documentation, support, secrets/personal data, scan result and version integrity. Return approve, changes requested, reject or escalate with reason codes.

## Output
Provide a concise decision, evidence reviewed, requirement IDs, findings, changes made or required, tests, risks and follow-up owner.
