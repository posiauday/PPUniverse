# Marketplace Review

Use for creator submissions and release moderation. Check ownership, license, claims, metadata, compatibility, accessibility, documentation, support, secrets/personal data, scan result and version integrity. Return approve, changes requested, reject or escalate with reason codes.

## Output
Provide a concise decision, evidence reviewed, requirement IDs, findings, changes made or required, tests, risks and follow-up owner.
